Unit I

Internet and WWW

Internet and its applications, e-mail, telnet, FTP, e-commerce, video conferencing, e-business, ISP, DNS, internet address, WWW and its evolution, URL, browsers, search engines, web servers, proxy server, HTTP.

Think of it like this

The Internet is the road network. The Web is only one kind of vehicle running on those roads (the one that carries web pages). E-mail, FTP and video calls are other vehicles on the same roads. Students mix these two up all the time, so say it early and repeat it.

What is the Internet?

The Internet is a worldwide network of networks. Millions of smaller networks (homes, colleges, companies, governments) are joined together, and every device on them can talk to every other device because they all follow the same rules, called the TCP/IP protocols.

  • Nobody owns it. Many organisations own pieces of it (cables, routers, servers). No single company or country controls the whole thing.
  • It began as ARPANET in 1969, a US defence-funded project that connected a few universities.
  • Data travels in packets. A file is cut into small pieces, each piece is sent separately through routers (possibly by different paths), and they are joined back together at the destination. This is called packet switching.
  • Protocol = an agreed set of rules for communication. TCP splits data and makes sure it all arrives; IP gives each device an address and routes the packets.
Exam answer

The Internet is a global system of interconnected computer networks that use the TCP/IP protocol suite to exchange data and provide services such as the World Wide Web, e-mail, file transfer and video conferencing.

E-mail (electronic mail)

Sending messages (text plus attachments) from one person to another over the internet, almost instantly. Address format: username@domain, for example asha@gmail.com. The @ separates the person from the mail server that holds their mailbox.

Telnet

Telnet (teletype network) lets you log in to a remote computer and use it through a text window, as if you were sitting at it. Type telnet hostname, enter username and password, then run commands on the far machine. It uses TCP port 23.

Outdated

Telnet sends everything, including your password, as plain readable text, so anyone listening can steal it. It has been replaced by SSH (Secure Shell, port 22), which encrypts everything. Telnet is still handy for testing whether a port is open.

FTP (File Transfer Protocol)

FTP is the standard way to upload and download files between your computer (client) and a server. Port 21 carries commands; port 20 carries data in active mode.

  • Login: with a username and password, or as anonymous FTP (username anonymous, your e-mail as password) for public downloads.
  • Common commands: ls (list), cd (change folder), get (download), put (upload), mget/mput (many files), bye (quit).
  • Transfer modes: ASCII (text files) and binary (images, zips, programs).
  • Today: used to upload website files to a hosting server (with tools like FileZilla). Secure versions are SFTP and FTPS.

Video conferencing

Live two-way audio and video between people in different places, over the internet. Needs a camera, microphone, speakers, a screen, a decent internet connection (bandwidth), and software such as Zoom, Google Meet or Microsoft Teams.

  • Point-to-point: two people. Multipoint: many people in one meeting.
  • Uses: online classes, business meetings, interviews, telemedicine, webinars.
  • Advantages: saves travel time and cost, screen sharing, recording.
  • Disadvantages: depends on bandwidth (lag, frozen video), privacy and security risks, less personal.

E-commerce and e-business

E-commerce means buying and selling goods or services over the internet, including the online payment. E-business is bigger: it means running every part of a business electronically (buying, selling, customer support, stock control, HR, accounting, working with suppliers).

E-commerce covers only the buying and selling transaction done online. E-business covers all business activities done online, so e-commerce is one part of e-business.

ISP, domain name server and internet address

Internet Service Provider (ISP)

A company that sells you a connection to the internet. Examples in India: Jio, Airtel, BSNL, ACT. Your device connects to the ISP, and the ISP connects you to the rest of the internet.

Ways to connect: dial-up (old, phone line, about 56 kbps), DSL/ADSL, cable, fibre (FTTH), mobile data (4G/5G), satellite. ISPs also give e-mail accounts, web hosting and sometimes a fixed IP address.

Domain Name System (DNS) and the domain name server

Computers find each other by numbers (IP addresses) but humans remember names. DNS is the phone book of the internet: it converts a domain name like google.com into an IP address like 142.250.190.14. The computers that do this job are DNS servers (name servers).

Reading a domain from right to left goes from biggest to smallest: www.example.co.in

How a name gets resolved

  • 1. Check the cachesBrowser and operating system remember recent lookups. If found, stop here.
  • 2. Ask the resolverUsually your ISP's DNS server (or 8.8.8.8, 1.1.1.1). It does the hunting for you.
  • 3. Root server"I don't know example.com, but the servers for .com are over there."
  • 4. TLD server (.com)"The name server for example.com is over there."
  • 5. Authoritative serverOwns the record and answers: "example.com is 93.184.216.34". The resolver caches it and returns it to your browser.

Useful record types: A (name to IPv4), AAAA (name to IPv6), MX (mail server), CNAME (alias), NS (name server).

Internet address (IP address)

Every device on the internet needs a unique address so data can find it. Three kinds of "address" get mixed up, so list them: the IP address (number), the domain name (friendly name for that number), and the e-mail address (person at a mail server).

  • IPv4: 32 bits, written as four numbers 0 to 255 separated by dots, like 192.168.1.10. About 4.3 billion addresses, which have run out.
  • IPv6: 128 bits, written in hexadecimal like 2001:0db8:85a3::8a2e:0370:7334. Practically unlimited addresses.
  • Static IP never changes; dynamic IP is handed out temporarily by DHCP.
  • 127.0.0.1 is localhost: "this same computer". Private ranges that don't work on the public internet: 10.x.x.x, 172.16-31.x.x, 192.168.x.x.

The World Wide Web (WWW) and its evolution

The Web is a huge collection of linked documents (web pages) stored on web servers and viewed with a browser. It stands on three inventions: URL (address of a page), HTTP (how the page is fetched) and HTML (how the page is written).

Inventor: Tim Berners-Lee, at CERN (Switzerland). Proposal 1989, first browser and server 1990, opened to the public 1991. He also founded the W3C in 1994 to keep web standards.

Terms: web page (one document), website (collection of pages), home page (the first page of a site), hyperlink (clickable link), hypertext (text containing links).

Uniform Resource Locator (URL)

A URL is the complete address of a resource on the internet, telling the browser which protocol to use, which server to contact, and which file to ask for.

https://www.example.com:443/courses/web.html?unit=1&topic=url#intro
Scheme (protocol) Host (domain name) Port (optional) Path to the file Query string (data) Fragment (place in page)
  • Schemes: http, https, ftp, mailto, file.
  • Absolute URL has everything (https://site.com/a/b.html). Relative URL is only the path from the current page (b.html or ../img/logo.png).
  • Spaces and special characters are encoded: a space becomes %20.
  • Default ports: http 80, https 443, ftp 21, so you normally don't see them.

A browser is software that requests web pages from servers, and displays them by reading HTML, CSS and JavaScript. Inside every browser: a user interface (address bar, tabs), a rendering engine (draws the page), a JavaScript engine (runs scripts) and a networking part (HTTP).

Search engines

A search engine is a website with a huge database of web pages that finds pages matching the words you type. It works in three steps:

  • 1. CrawlA program called a crawler (spider, bot) follows links and reads pages all over the web
  • 2. IndexWords and details from each page are stored in a giant searchable index
  • 3. RankWhen you search, an algorithm sorts matching pages by relevance and quality and shows the result page (SERP)

Examples: Google, Bing, DuckDuckGo, Yahoo, Baidu. Types: crawler-based (Google), directory-based (early Yahoo, pages sorted by humans into categories), meta-search (asks several engines and combines results).

Remember

Chrome is a browser. Google is a search engine. A browser shows pages; a search engine helps you find them.

Web servers and proxy server

Web server

A web server is a program (and the computer running it) that stores website files and sends them to browsers when they ask over HTTP. It waits on port 80 (HTTP) or 443 (HTTPS). For plain files it just sends them; for dynamic pages it first runs a script (PHP, ASP.NET, Node.js) and sends the result.

A very popular modern one is Nginx, known for speed under heavy load.

Proxy server

A proxy is a middleman between your computer and the internet. You ask the proxy for a page, the proxy fetches it for you and passes it back. Think of the school office: students don't go to the principal directly; the office handles requests.

  • Caching: keeps copies of popular pages so the next person gets them faster and bandwidth is saved.
  • Filtering: colleges and offices block certain sites.
  • Anonymity: the website sees the proxy's IP, not yours.
  • Security and logging: checks traffic and records who accessed what.

Forward proxy sits in front of clients (the kind above). A reverse proxy sits in front of servers, spreading load and protecting them (Nginx, Cloudflare).

HTTP protocol

HTTP (HyperText Transfer Protocol) is the set of rules browsers and web servers use to talk. It works as request and response: the browser asks, the server answers, and that's the end of the conversation.

  • Stateless: the server doesn't remember you between requests. Websites add memory using cookies and sessions.
  • Text-based, port 80. HTTPS is HTTP wrapped in TLS encryption, port 443, shown by the padlock.
  • Versions: 1.0 (1996), 1.1 (1997), 2 (2015), 3 (2022).

What happens when you press Enter (ties the unit together)

If you ever want one story that uses every term in this unit, tell this one. You type https://www.example.com/index.html and press Enter:

  • Browser splits the URLscheme https, host www.example.com, path /index.html
  • DNS lookupDomain name becomes an IP address (through your ISP's DNS server)
  • ConnectionBrowser opens a TCP connection to that IP on port 443, and sets up TLS encryption
  • HTTP requestBrowser sends GET /index.html (through a proxy if one is configured)
  • Server respondsThe web server (Apache, IIS, Nginx) sends status 200 OK and the HTML
  • Browser rendersReads the HTML, fetches CSS, JavaScript and images with more requests, and draws the page

Likely questions and checklist

Differentiate between the Internet and the World Wide Web.

The Internet is the global network of connected computers (hardware and protocols). The WWW is a service that runs on it: a collection of linked web pages accessed through HTTP and a browser. E-mail and FTP also use the internet but are not the web.

What is DNS? Explain how it works.

DNS converts domain names to IP addresses. The browser checks its cache, then asks a resolver (usually the ISP's). The resolver asks a root server, then the TLD server (.com), then the authoritative name server, which returns the IP. The result is cached.

Explain SMTP, POP3 and IMAP.

SMTP sends e-mail from client to server and between servers. POP3 downloads mail to the device (usually deleting it from the server). IMAP keeps mail on the server and syncs it across devices.

What is a URL? Explain its parts.

A URL is the address of a resource on the web. Parts: scheme (https), host (www.example.com), optional port (:443), path (/courses/web.html), query string (?unit=1) and fragment (#intro).

Compare Apache and IIS.

Apache is free, open source and cross-platform, configured through text files, and popular with PHP/MySQL. IIS is Microsoft's server, runs only on Windows, has a graphical manager and is popular with ASP.NET.

What is a proxy server? Give its uses.

An intermediary between clients and the internet. Uses: caching for speed, filtering and blocking sites, hiding the client's IP address, and improving security and logging.

Explain the HTTP request and response with methods and status codes.

The client sends a request (method, path, headers, optional body) and the server returns a response (status code, headers, body). Methods: GET, POST, PUT, DELETE, HEAD. Status: 2xx success, 3xx redirect, 4xx client error (404), 5xx server error (500).

Differentiate between e-commerce and e-business, and name the types of e-commerce.

E-commerce is online buying and selling; e-business is all business activity done electronically, so e-commerce is a part of it. Types: B2B, B2C, C2C, C2B, B2G.

HTML tag reference

HTML (HyperText Markup Language) is the language used to describe the structure and content of a web page. It is a markup language, not a programming language: it labels things ("this is a heading", "this is a link") and the browser decides how to show them.

  • Tag: a keyword in angle brackets, like <p>. Most come in pairs: an opening tag <p> and a closing tag </p>.
  • Element: opening tag + content + closing tag. Empty (void) elements have no closing tag: <br>, <hr>, <img>, <input>.
  • Attribute: extra information inside the opening tag, as name="value", like <a href="page.html">.
  • Tags are not case-sensitive in HTML, but lowercase is the standard.
html
<!DOCTYPE html>                     <!-- tells the browser: this is HTML5 -->
<html lang="en">
<head>                              <!-- information ABOUT the page, not shown -->
  <meta charset="UTF-8">
  <title>My First Page</title>       <!-- text on the browser tab -->
</head>
<body>                              <!-- everything the visitor SEES -->
  <h1>Hello, world</h1>
  <p>This is a paragraph.</p>
</body>
</html>

Images and image maps

The image tag

html

What is an image map?

An image map is one image with several clickable regions, and each region links to a different place. Examples: a map of India where each state links to its page, or a picture of a computer where clicking the monitor, keyboard or mouse opens different pages.

Client-side image maps

The browser itself works out which region was clicked. All the information sits in the HTML. Two parts: the image with usemap, and a <map> containing <area> tags.

html
<img src="computer.png" usemap="#pcmap" alt="Computer parts">

<map name="pcmap">

  <area shape="circle" coords="200,50,40"       href="mouse.html"    alt="Mouse">
  <area shape="poly"   coords="20,120,80,120,50,160" href="stand.html" alt="Stand">
  <area shape="default" href="parts.html" alt="All parts">
</map>

Likely questions and checklist

Differentiate between block-level and inline elements.

Block-level elements start on a new line and take the full available width (div, p, h1, ul, table). Inline elements flow within a line and take only the width they need (span, a, b, img).

What are image maps? Differentiate between client-side and server-side image maps.

An image map is an image with multiple clickable regions linking to different URLs. In client-side maps the browser resolves the click using <map> and <area> (usemap). In server-side maps the click coordinates are sent to a server program (ismap), which is slower and needs a server.

Explain the attributes of the <area> tag.

shape (rect, circle, poly, default), coords (pixel values for that shape), href (destination), alt (alternative text) and target.

Write the HTML for a table with a merged header cell.

Use <th colspan="2"> inside the first row, then normal <td> cells. See the colspan/rowspan example above.

Difference between GET and POST methods in a form.

GET appends data to the URL (visible, limited length, bookmarkable), used for searches. POST sends data in the request body (hidden, no practical limit), used for sensitive data and uploads.

What are frames? Why are they no longer used?

Frames divide the window into independent panes, each with its own HTML file, using <frameset> and <frame>. They break bookmarking and the Back button, harm SEO and accessibility, and were removed in HTML5. <iframe> and CSS layouts replace them.

What are executable content tags? Give examples.

Tags that embed code or programs that run in the browser: <script>, <applet>, <object> and <embed>.

Ordered vs unordered vs definition lists.

Ordered (<ol>) numbers items, unordered (<ul>) uses bullets, definition (<dl>) pairs terms (<dt>) with descriptions (<dd>).

Introduction to JavaScript

JavaScript is a lightweight scripting language that makes web pages interactive. HTML gives the structure, CSS gives the looks, JavaScript gives the behaviour.

  • Created by Brendan Eich at Netscape in 1995 in about ten days. Names: Mocha, then LiveScript, then JavaScript. It was named to ride on the fame of Java, but JavaScript is not Java. They are different languages.
  • Standardised as ECMAScript (ES). "ES6" (2015) added let, const, arrow functions, classes and modules.
  • Interpreted: the browser runs it line by line, no compile step. Dynamically typed: a variable can hold any type. Case-sensitive: name and Name are different.

<!-- 3. External file (best practice) -->

Ways to show output

  • document.write("text"): writes into the page. element.innerHTML = "text": changes an element's content.

JavaScript security

The browser runs code from websites you don't fully trust, so JavaScript is deliberately kept in a sandbox: a restricted area where it can do a limited set of things.

  • No access to your files or system. A page cannot read your documents, run programs or install software.
  • Same-origin policy: a script from one site (same protocol, domain and port) cannot read data from another site. This stops a bad site from reading your bank's page in another tab. Sharing is allowed only if the other server opts in (CORS).
  • Limited windows and pop-ups: scripts can't freely close windows they didn't open, and pop-ups need a user action.
  • Cookies are limited per site; HttpOnly cookies can't be read by scripts at all.

Short-circuit evaluation

Logical operators stop as soon as the answer is known, and they return one of the actual operands, not just true or false.

  • a && b: if a is falsy, return a and never look at b. Otherwise return b.
  • a || b: if a is truthy, return a and never look at b. Otherwise return b.
js

console.log("Asha" || "Guest"); // "Asha"

let username = input || "Guest";    // default value

let count = data ?? 0;              // ?? only replaces null or undefined (modern)

Likely questions and checklist

What is JavaScript? Differentiate between JavaScript and Java.

JavaScript is an interpreted, dynamically typed scripting language for web interactivity. Java is a compiled, statically typed, general-purpose object-oriented language. They are unrelated apart from the name. JavaScript runs in browsers and on Node.js; Java runs on the JVM.

Differentiate between client-side and server-side JavaScript.

Client-side runs in the browser and manipulates the page and events. Server-side (Node.js, earlier LiveWire) runs on the server and works with databases and files, sending only the result to the client.

Difference between == and ===.

== compares values after converting types, so 5 == "5" is true. === compares value and type without conversion, so 5 === "5" is false.

Explain increment and decrement operators with prefix and postfix.

++ adds one and -- subtracts one. Postfix (x++) returns the old value then changes x. Prefix (++x) changes x then returns the new value.

What is short-circuit evaluation?

Logical operators stop evaluating as soon as the result is known. && stops at the first falsy operand, || at the first truthy one, and they return that operand.

Explain any four special operators.

Conditional ?: (one-line if/else), comma , (evaluates several expressions, returns the last), delete (removes an object property), new (creates an object from a constructor), this (current object), void (returns undefined).

Difference between while and do...while, and between break and continue.

while tests the condition first and may never run. do...while runs the body once before testing. break exits the loop; continue skips to the next iteration.

What is the output of: let x = 5; let y = x++ + ++x;

x++ gives 5 (x becomes 6), then ++x makes x 7 and gives 7. So y = 5 + 7 = 12 and x = 7.

Introduction to XML

XML (eXtensible Markup Language) is a text format for storing and transporting data. You invent your own tags to describe your data, so the file explains itself. It was made a W3C recommendation in 1998.

The key difference from HTML: HTML displays data; XML describes data.

Why XML?

  • Self-descriptive: <price>250</price> tells you what 250 is.
  • Platform and language independent: any system can read plain text, so different applications can exchange data.
  • Separates data from presentation: one XML file can be shown many ways using XSL.
  • Where it is used: RSS feeds, sitemaps, SVG images, Microsoft Office files (.docx is a zip of XML), Android layouts, configuration files, SOAP web services.
Remember

XML doesn't do anything by itself. It is just structured data waiting for a program to read it. Today many APIs use JSON instead, but XML is still everywhere in enterprise systems and file formats.

Well-formed vs valid

Well-formed means the document obeys XML's syntax rules. Valid means it is well-formed and also follows the rules of a DTD or Schema. A parser rejects a document that is not well-formed.

  • There must be exactly one root element.
  • Every start tag needs an end tag (or be self-closing: <br/>).
  • Tags must be properly nested: <a><b></b></a> is fine, <a><b></a></b> is not.
  • Tag names are case-sensitive: <Name> and <name> are different.
  • Attribute values must be quoted.
  • Special characters must be escaped (&lt;, &amp; and so on).
  • Names can't start with a number or contain spaces.

Element or attribute?

Both can hold data, so people ask which to use. A good rule: use elements for the data itself (name, marks) and attributes for information about the data (an id, a unit, a language). Attributes can't hold structure or repeat, elements can.

Creating XML DTDs

A DTD (Document Type Definition) is a set of rules describing which elements and attributes a document may contain, in what order, and how many times. It is the older way of validating XML. It uses its own non-XML syntax.

Internal DTD (inside the XML file)

xml
<?xml version="1.0"?>
<!DOCTYPE students [
  <!ELEMENT students (student+)>
  <!ELEMENT student (name, course, marks)>
  <!ATTLIST student id CDATA #REQUIRED>
  <!ELEMENT name (#PCDATA)>
  <!ELEMENT course (#PCDATA)>
  <!ELEMENT marks (#PCDATA)>
]>
<students>
  <student id="101"><name>Asha</name><course>BCA</course><marks>82</marks></student>
</students>

External DTD (separate file)

xml
<!-- in students.xml -->
<!DOCTYPE students SYSTEM "students.dtd">

<!-- students.dtd contains only the rules -->
<!ELEMENT students (student+)>
<!ELEMENT student (name, course, marks)>
...

Use an external DTD when many documents share the same rules. Read the internal example line by line:

  • <!DOCTYPE students [ ... ]>: the name after DOCTYPE must match the root element.
  • <!ELEMENT students (student+)>: students contains one or more student elements.
  • <!ELEMENT student (name, course, marks)>: exactly these three children, in this order.
  • <!ELEMENT name (#PCDATA)>: contains only text (parsed character data).
  • <!ATTLIST student id CDATA #REQUIRED>: student must have an attribute id holding text.

Limitations of DTD (why Schema was created)

DTD is not written in XML, has no real data types (everything is text), doesn't support namespaces well, and can't say things like "marks is a number between 0 and 100".

XML Schemas

An XML Schema (XSD, XML Schema Definition) does the same job as a DTD, but it is written in XML itself and is far more powerful: it has data types, ranges, patterns and namespace support.

xml
<?xml version="1.0"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">

  <xs:element name="students">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="student" maxOccurs="unbounded">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="name"   type="xs:string"/>
              <xs:element name="course" type="xs:string"/>
              <xs:element name="marks"  type="xs:integer"/>
            </xs:sequence>
            <xs:attribute name="id" type="xs:integer" use="required"/>
          </xs:complexType>
        </xs:element>
      </xs:sequence>
    </xs:complexType>
  </xs:element>

</xs:schema>

<students xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:noNamespaceSchemaLocation="students.xsd">

Key pieces

  • Simple element: only text, no children or attributes: <xs:element name="name" type="xs:string"/>.
  • Complex type: an element with children and/or attributes; xs:sequence fixes their order, xs:choice allows one of several, xs:all allows any order.
  • Occurrence: minOccurs and maxOccurs (a number or "unbounded") replace the DTD symbols ? * +.
  • Built-in types: xs:string, xs:integer, xs:decimal, xs:boolean, xs:date, xs:time.

Restricting values

xml

    <xs:restriction base="xs:integer">
      <xs:minInclusive value="0"/>
      <xs:maxInclusive value="100"/>
    </xs:restriction>
  </xs:simpleType>
</xs:element>

<!-- pattern: exactly 6 digits (a PIN code) -->
<xs:simpleType name="pinType">
  <xs:restriction base="xs:string">
    <xs:pattern value="[0-9]{6}"/>

</xs:simpleType>

XSL

XSL (eXtensible Stylesheet Language) is the styling language for XML. Since XML has no built-in look, XSL says how to display or convert it. It is a family of three parts:

PartJob
XSLTTransforms an XML document into another form (HTML, another XML, plain text). This is the part everyone means by "XSL".
XPathA syntax to pick parts of an XML document: students/student, @id, student[marks > 75]
XSL-FOFormatting objects, for print output such as PDF

Example: show the student list as an HTML table

First connect the stylesheet from the XML file (put this line right after the declaration):

xml
<?xml-stylesheet type="text/xsl" href="students.xsl"?>

Then write students.xsl:

xml
<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0"
    xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

  <xsl:template match="/">                      <!-- match the whole document -->
    <html>
      <body>
        <h2>Student Marks</h2>
        <table border="1">
          <tr><th>ID</th><th>Name</th><th>Marks</th></tr>

          <xsl:for-each select="students/student">        <!-- loop -->
            <xsl:sort select="marks" data-type="number" order="descending"/>
            <tr>
              <td><xsl:value-of select="@id"/></td>      <!-- attribute -->
              <td><xsl:value-of select="name"/></td>     <!-- child element -->
              <td>
                <xsl:choose>
                  <xsl:when test="marks &gt;= 75">
                    <b><xsl:value-of select="marks"/></b>
                  </xsl:when>
                  <xsl:otherwise>
                    <xsl:value-of select="marks"/>
                  </xsl:otherwise>
                </xsl:choose>
              </td>
            </tr>
          </xsl:for-each>
        </table>
      </body>
    </html>
  </xsl:template>

</xsl:stylesheet>
XSL elementDoes
xsl:stylesheetRoot of the stylesheet (with the xsl namespace)
xsl:template match="..."A rule: "when you meet this part of the XML, produce this output"
xsl:value-of select="..."Output the value of the selected node
xsl:for-each select="..."Loop over every matching node
xsl:sort select="..."Sort inside a loop
xsl:if test="..."Output only when a condition is true (no else)
xsl:choose / when / otherwiseIf / else-if / else

If the XSL page shows blank when you test it

Chrome blocks XSLT on files opened straight from disk (file://). Either open the XML in Firefox, or run a tiny local server from the folder: python -m http.server, then visit http://localhost:8000/students.xml.

Simpler alternative

You can also style XML with plain CSS by adding <?xml-stylesheet type="text/css" href="style.css"?> and writing rules like student { display: block; }. CSS only styles; XSL can also reorder, filter and transform.

Likely questions and checklist

What is XML? Differentiate between XML and HTML.

XML is a markup language for storing and transporting data using user-defined tags. HTML has fixed tags and displays data. XML is case-sensitive and strict; HTML is forgiving. XML describes what data is; HTML describes how it appears.

What is a well-formed XML document? State the rules.

One that obeys XML syntax: exactly one root element, all tags closed, proper nesting, case-sensitive names, quoted attribute values, and special characters escaped.

Differentiate between well-formed and valid XML.

Well-formed means correct syntax. Valid means well-formed and also conforming to a DTD or Schema.

What is a DTD? Explain internal and external DTD with an example.

A DTD defines the legal structure of an XML document (elements, attributes, order, occurrence). An internal DTD is placed inside the XML file within <!DOCTYPE root [ ... ]>; an external DTD is a separate .dtd file referenced with <!DOCTYPE root SYSTEM "file.dtd">. Give the students example.

Differentiate between DTD and XML Schema.

Schema is written in XML, supports data types, restrictions and namespaces, and gives finer control over occurrences. DTD uses non-XML syntax, has essentially no data types and no restrictions.

What is XSL? Explain XSLT with an example.

XSL is a stylesheet language for XML made of XSLT (transformation), XPath (selecting nodes) and XSL-FO (formatting). XSLT uses templates such as xsl:template, xsl:for-each and xsl:value-of to convert XML into HTML. Give the students table example.

What are the components of an XML document?

Declaration, root element, child elements, attributes, text, comments, CDATA sections, processing instructions and entity references.

CSS: external stylesheet and the three basic selectors

CSS (Cascading Style Sheets) controls how HTML looks: colours, fonts, spacing and layout. HTML says what something is; CSS says how it looks.

Way to add CSSExampleUse
Inline<p style="color:red">One-off fixes only
Internal<style>...</style> in the headA single page
External<link rel="stylesheet" href="style.css">Whole website (best practice)

External CSS in practice

Put all the styles in one file, style.css, link it from every page, and use selectors to say which elements each rule applies to. The three basic selectors are type, class and id.

SelectorWritten asMatchesIn HTML
Type (element)p { }Every element of that tagNo attribute needed
Class.note { }Every element with that class (reusable)class="note"
ID#title { }The one element with that id (must be unique)id="title"
index.html
<!DOCTYPE html>
<html>
<head>
  <title>Selectors demo</title>
  <link rel="stylesheet" href="style.css">   <!-- external CSS -->
</head>
<body>
  <h1 id="title">My Page</h1>
  <p>A normal paragraph.</p>
  <p class="note">An important paragraph.</p>
  <p class="note">Another important paragraph.</p>
</body>
</html>
style.css
/* 1. Type selector: styles every <p> */
p      { color: #333; font-size: 18px; }

/* 2. Class selector: styles every element with class="note" */
.note  { background: #fff3d1; padding: 10px; }

/* 3. ID selector: styles only the element with id="title" */
#title { color: navy; text-align: center; }

The result: all three paragraphs get grey text (type), the two notes also get a yellow background (class), and the heading is navy and centred (id).

Remember

Use a class when many elements share a style, and an id only for one unique element. Other selectors build on these: grouping h1, h2 { }, descendant nav a { }, pseudo-class a:hover { } and attribute input[type="text"] { }.

Exam answer: cascade and specificity

When rules conflict, the browser picks by specificity (inline > id > class/attribute/pseudo-class > element), then by source order (later wins). !important overrides both, so avoid it.

Box model, units and colours

Every element is a box: content, then padding, then border, then margin outside. Add box-sizing: border-box so width includes padding and border, which makes sizes predictable.

UnitMeaningGood for
pxFixed pixelsBorders, shadows
%Relative to the parentFluid widths
em / remRelative to font size (rem: root)Fonts, spacing
vw / vh1% of viewport width / heightFull-screen sections

Colours can be names (red), hex (#1a4bd0), rgb(26,75,208) or hsl(224,78%,46%).

Layout: display, position, Flexbox and Grid

Old pages used tables and floats for layout. Today you use Flexbox for one-dimensional layouts (a row or a column) and Grid for two-dimensional ones (rows and columns together).

css
.nav   { display: flex; justify-content: space-between; align-items: center; gap: 12px; }

.cards { display: grid;
         grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
         gap: 16px; }

position values: static (default), relative (offset from its own place), absolute (relative to the nearest positioned parent), fixed (stuck to the screen), sticky (scrolls, then sticks).

Responsive web design

A responsive website adapts to any screen size, from phone to desktop, using one HTML file. Three ingredients:

  1. Viewport meta tag so phones do not zoom out: <meta name="viewport" content="width=device-width, initial-scale=1">
  2. Fluid sizing: percentages, rem, max-width, and images with max-width:100%; height:auto.
  3. Media queries that change the layout at breakpoints.
css
/* mobile-first: base styles are for phones */
.layout { display: block; }

@media (min-width: 768px) {          /* tablets and up */
  .layout { display: grid; grid-template-columns: 220px 1fr; }
}
Remember

"Mobile-first" means writing the phone layout first and using min-width queries to add features for larger screens. It is easier than shrinking a desktop design down.

User experience and usability

Usability is how easily people can finish their task on a site. User experience (UX) is the whole feeling of using it. Principles worth stating in an answer:

  • Consistency: the same navigation, colours and button styles on every page.
  • Clear navigation: users should always know where they are and how to go back.
  • Feedback: show loading, success and error messages.
  • Readability: enough colour contrast, sensible font size (16px or more for body text), short lines.
  • Accessibility: alt text, labels on form fields, keyboard-usable controls, semantic tags (<nav>, <main>).
  • Speed: compressed images, little unused code.

Google Antigravity in brief

Antigravity is Google's agent-first IDE, built on a VS Code-style editor. Its agents can work across the editor, terminal and a built-in browser. It has an Editor view for hands-on coding with an agent sidebar, and a Manager view for running several agents in parallel. Tools like this change quickly, so check the official site for the current version, pricing and region availability.

A workflow that works for MERN projects

  1. 1. Plan before codeAsk the AI for a plan: folder structure, API routes, MongoDB schemas, React components. Edit the plan yourself before it writes anything.
  2. 2. Build in small stepsOne feature per request ("add a POST /api/notes route with validation"), not "build my whole app".
  3. 3. Review the diffRead every change the agent made. Look for hard-coded secrets, missing validation, unsafe queries and code you do not understand.
  4. 4. Run and testRun the app, click through it, and ask the AI to write tests. If you cannot see it work, it is not done.
  5. 5. Commit with GitCommit after every working step so you can undo a bad AI change.

Habits that make you better, not lazier

  • Try first, then ask. Spend 15 minutes on the problem, then ask for a hint before the full answer.
  • Ask "why". "Why does this useEffect run twice?" teaches more than "fix this".
  • Give the AI context: the exact error, the relevant code and your stack.
  • Never paste secrets (API keys, passwords, database URLs) into an AI tool.
  • Verify packages and APIs. AI can invent functions or libraries that do not exist.
  • Keep your fundamentals strong. Exams and interviews test whether you understand the code, not whether an AI can write it.
Remember

An AI tool is like a very fast junior developer: quick, confident, and sometimes wrong. You are the one who reviews, tests and takes responsibility for the code.

  • Give an agent a bug in your project and ask it to find the cause and explain it before fixing.

Likely questions and checklist

What is CSS? Explain the types of CSS with an example.

CSS is a stylesheet language that controls the presentation of HTML. Inline CSS uses the style attribute on one element, internal CSS uses a <style> block in the page, and external CSS links a separate .css file with <link>. External is best because one file styles the whole site.

Explain the CSS box model.

Every element is a rectangular box made of content, padding, border and margin, from inside to outside. Total width = content + padding + border + margin (unless box-sizing: border-box is used).

What is responsive web design? How is it achieved?

Designing a site so one page adapts to all screen sizes. It uses the viewport meta tag, fluid units and flexible images, Flexbox/Grid, and media queries at breakpoints.

Differentiate between Flexbox and Grid.

Flexbox lays items out along one axis (row or column) and suits components like navbars. Grid controls rows and columns at once and suits whole-page or card layouts.

Explain type, class and id selectors with an example using an external stylesheet.

Link style.css with <link rel="stylesheet" href="style.css">. A type selector (p { }) styles every element of that tag. A class selector (.note { }) styles all elements with class="note". An id selector (#title { }) styles the single element with id="title", which must be unique on the page.

What are AI-assisted development tools? Name some.

Tools that help write and fix code: chat assistants (Claude, ChatGPT, Gemini), editor assistants (GitHub Copilot, Cursor) and agentic tools such as Google Antigravity and Claude Code, which can plan, edit several files, run commands and tests. Developers still review and test the output.

What is the MERN stack?

A JavaScript full-stack: MongoDB (NoSQL database), Express.js (back-end framework), React (front-end library) and Node.js (server runtime). A React front end calls an Express/Node API, which reads and writes MongoDB.
